# FL2000 USB-VGA DAC (osmo-fl2k)

Commodity USB 3.0 → VGA adapters based on the Fresco Logic **FL2000** can be driven as a continuous 8-bit DAC with [osmo-fl2k](https://osmocom.org/projects/osmo-fl2k/wiki).

**Lab role:** this device is most useful as a **baseband transmitter** (audio through low HF on the green VGA pin). It is not a VHF/UHF radio substitute. The HackRF or Baofeng cover amateur VHF/UHF; see [Baofeng simplex bring-up](../bringup/baofeng-simplex.md).

USB VID:PID `1d5c:2000`. Not a `make stage` board; no entry in `stage.json`.

## Specification

| Item | Value |
| --- | --- |
| Chip | Fresco Logic FL2000 |
| Role | 3-channel 8-bit real DAC (VGA R/G/B) — **baseband TX** |
| Host tools | osmo-fl2k **0.2.0** under `.tools/fl2k-local/` |
| USB | `1d5c:2000` (needs USB 3 for useful sample rates) |
| Sample rate | ~100 Msps typical here; host USB caps ~115–157 Msps (USB 2 ≈ 14 Msps) |
| Sample format | signed or unsigned int8 per channel |
| Analog outs | VGA **R, G, B** only — HSYNC/VSYNC are digital sync, not DAC pins |
| Preferred pin | **Green** (best HF response on this bench) |
| Lab use | Baseband / low-HF conducted TX (scope, AM BCB, tones ≤ ~50 MHz) |

Stock `fl2k_file` / `fl2k_fm` fill only `r_buf` (red). For green-only or RGB, the local tools under `.tools/fl2k-local/` may be patched to set `g_buf` / `b_buf`.

## Usable frequency range (this bench)

Digitally, osmo-fl2k can place energy at an IF and at images \(f_s \pm f_{\mathrm{IF}}\) (and dirty harmonics). The **VGA analog path** is the real limit.

| Band | Verdict on this hardware |
| --- | --- |
| **DC → ~50 MHz (baseband / low HF)** | **Usable** — primary role. Clean CW at 1 MHz and 50 MHz (Nyquist @ 100 Msps); AM Morse at 540 kHz verified |
| AM broadcast (~540–1700 kHz) | Usable as baseband AM (verified at 540 kHz) |
| **FM broadcast (~88–108 MHz)** | **Outside usable range** — WBFM images (e.g. 87–88 MHz) not useful here despite classic osmo-fl2k demos |
| 2 m / other VHF (e.g. 146.55 MHz) | Outside usable range as a direct image; weak/ugly if present at all |
| UHF via harmonics | Not a lab TX path |

**Lab policy:** drive the FL2000 as a **baseband source**. Do not plan FM-BCB or amateur VHF/UHF work on the dongle alone.

### Heterodyne (future)

To reach other bands, mix the FL2000 baseband/IF with an external LO (chip frequency generator + mixer from the [accessories](accessories.md) catalog), then filter. That path is not brought up yet; until then, treat the FL2000 as baseband-only.

### Example baseband placements

| Intent | \(f_s\) | Product on green |
| --- | --- | --- |
| 1 MHz scope tone | 100 Msps | 1 MHz |
| 50 MHz CW | 100 Msps | 50 MHz (Nyquist) |
| AM Morse @ 540 kHz | 10 Msps | 540 kHz |

## Bench-verified settings

### AM Morse callsign @ 540 kHz (AM BCB low end)

Verified on this host: green pin, conducted/pad into an AM radio tuned to **540 kHz** (54 × 10 kHz).

| Setting | Value |
| --- | --- |
| Carrier | **540000 Hz** |
| Mode | AM Morse (MCW), depth **0.7**, tone **700 Hz**, **18 WPM** |
| Text | `AD6XH AD6XH` (pass callsign via `--callsign` / `RAD_LAB_CALLSIGN`; never hardcode in labs) |
| Channel | **green** (`g_buf` only; patched `fl2k_file`) |
| Sample rate | **10000000** (10 Msps) — must match file generation |
| Buffer | ~8.533 s → `reports/hackrf/uv5r/tx_callsign_AD6XH_am_540khz_fl2k.s8` |
| Play | `-r 8` ≈ 60 s |
| Meta | `reports/hackrf/uv5r/tx_callsign_AD6XH_am_540khz_fl2k_meta.json` |

**Sample-rate pitfall:** requesting **2 Msps** was rejected; the device ran at ~7.78 Msps and scaled the carrier off 540 kHz. Prefer **10 Msps** or **100 Msps** grids that `fl2k_file` accepts without a “not possible” retune message.

```bash
export LD_LIBRARY_PATH="$PWD/.tools/fl2k-local/lib"
.tools/fl2k-local/bin/fl2k_file -s 10000000 -r 8 \
  reports/hackrf/uv5r/tx_callsign_AD6XH_am_540khz_fl2k.s8
```

### Baseband quick host commands

Privileged USB access and a large usbfs buffer help. Prefer the green pin.

```bash
export LD_LIBRARY_PATH="$PWD/.tools/fl2k-local/lib"

# 1 MHz signed int8 → green for ~60 s
.tools/fl2k-local/bin/fl2k_file -s 100000000 -r 60 path/to/tone_1mhz.s8

# 50 MHz Nyquist CW @ 100 Msps
.tools/fl2k-local/bin/fl2k_file -s 100000000 -r 60 \
  reports/hackrf/uv5r/tx_sine_50mhz_fl2k.s8
```

Do not use `fl2k_fm` images into the FM broadcast or 2 m bands on this bench — those are outside the usable range. Do not radiate without filtering and a license-appropriate setup.
