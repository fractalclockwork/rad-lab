# Methodology

A general engineering process for **agentic work that spans software and physical systems**, developed with [rad-lab](../../README.md) as the case study.

**Terminology:** **HWIL** = hardware-in-the-loop. **Human** / **human-in-the-loop** = operator role (always spelled out). Assent env vars are `HUMAN_*`.
